# Problem Statement

Detection and Characterization of Subsurface Ice in Lunar South Polar Regions Using Chandrayaan-2 Radar and Imagery Data for Landing Site and Rover Traverse Planning.

This project addresses the challenge of identifying subsurface ice deposits in the lunar south polar region using radar and imagery data from Chandrayaan-2. The lunar poles are important because permanently shadowed regions can preserve water ice. Detecting these deposits is essential for future lunar exploration, resource utilization, and mission safety.

The project aims to:
- process radar and optical imagery data,
- extract features related to ice presence,
- detect probable ice-bearing regions,
- evaluate candidate landing sites,
- recommend rover traverse paths based on terrain and resource potential.

The final outcome is a decision-support tool for mission planners to locate resource-rich and safe regions in lunar south polar terrain.
